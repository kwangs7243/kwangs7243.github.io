소개

자동차 정비에서
백엔드 개발로

도구는 바뀌었지만 문제의 원인을 추적하는 방식은 이어졌습니다.

자동차 정비 현장에서 기술을 익히며 눈앞의 증상보다 원인을 찾아 문제를 해결하는 일을 경험했습니다. 새로운 분야에서 계속 배우고 성장하고 싶어 개발을 시작했고, Python으로 작은 프로그램을 직접 만들며 프로그래밍의 기초를 익혔습니다.

기능이 늘면서 코드가 복잡하게 얽히는 문제를 겪은 뒤 화면과 기능의 책임을 나누는 방법을 배웠습니다. Flask와 데이터베이스를 배우면서 관심은 기능 하나를 만드는 데서, 데이터와 여러 기능이 실제 사용자 서비스로 이어지는 전체 흐름으로 넓어졌습니다.

지금은 오류가 생기면 데이터와 실행 흐름을 따라 원인을 확인하고, 입력과 출력·실패 상태를 함께 고려하며 유지보수하기 쉬운 연결 구조를 만드는 연습을 이어가고 있습니다.
