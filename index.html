01 / 소개

작은 기능에서 시작해, 서비스의 전체 흐름을 보는 개발자로 성장했습니다.

자동차 정비 현장에서 근무한 뒤 프로그래밍 기초부터 다시 배우며 개발로 진로를 전환했습니다. 계산기·가계부·메모·할 일 관리 같은 작은 프로그램에 기능을 더하다가 하나의 파일에 코드가 얽히는 문제를 겪었고, 화면과 실제 기능의 책임을 나눠 구조를 정리하면서 책임 분리의 필요성을 처음 체감했습니다.

Flask와 DB를 배우며 관심은 개별 기능에서 서비스의 데이터 흐름으로 확장됐습니다. 두 팀 프로젝트에서는 데이터가 만들어지고 저장·처리되는 과정, 실패 조건과 기능 간 책임을 따라 문제를 해결했고, 현재는 데이터·AI 기능을 안정적으로 사용자 서비스에 연결하는 백엔드 개발자로 성장하는 것을 목표로 하고 있습니다.

06 / 성장 방향

기능을 만드는 것에서, 서비스가 끝까지 동작하는 조건을 보는 개발자로 성장하고 싶습니다.

두 프로젝트를 진행하며 DB 설계와 조회, API, 데이터 처리, 모델 결과 연동, 배치 자동화가 서로 분리된 문제가 아니라 하나의 서비스 흐름이라는 것을 배웠습니다.
